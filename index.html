📖 コールガイド（初心者向け）

コールとは？

丼が席に置かれる直前、店員から 「ニンニク入れますか？」 と聞かれます。この一言でトッピングをカスタマイズできます。

コールできる内容

コール内容増量
ニンニク刻みニンニク。風味が増す少し / 普通 / 増し
ヤサイもやし＋キャベツ。デフォでも大量普通 / 増し / 増し増し
アブラ背脂。スープにコクが加わる普通 / 増し / 増し増し
カラメ醤油ダレ追加。スープが濃くなる普通 / カラメ / カラメカラメ

初心者おすすめ

  • 最初は 「ニンニクなし、全部普通で」 が無難
  • ヤサイはデフォでもかなりの量。増しは覚悟が必要
  • 何も言わなければ「そのまま」もOK
  • 残すのはマナー違反とされることが多い。注文量は慎重に

食べ方のコツ

  • ヤサイの下に麺が埋まっているので最初にほぐすと食べやすい
  • 豚はスープに浸しながら食べると柔らかく感じる
  • 「天地返し」で麺をスープに沈める人も多い
