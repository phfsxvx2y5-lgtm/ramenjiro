📖 コールガイド（初心者向け）

コールとは？

丼が席に置かれる直前、店員から 「ニンニク入れますか？」 と聞かれます。この一言でトッピングをカスタマイズできます。何も言わなければデフォルト（標準）のまま提供されます。

コールできる内容

コール内容指定方法の例
ニンニク刻みニンニク。風味が強まるなし / 少し / 普通
ヤサイもやし＋キャベツ。デフォでも大量普通 / 増し / 増し増し
アブラ背脂。スープにコクが加わる普通 / 増し / 増し増し
カラメ醤油ダレ追加。スープが濃くなる普通 / カラメ / カラメカラメ

初心者おすすめコール

  • 一番無難なのは 「ニンニクなし、全部普通で」
  • ヤサイはデフォルトでもかなりの量。増しは上級者向け
  • 何も言わなければ「そのまま（デフォルト）」もOK
  • 食べきれる量をしっかり考えて注文しよう

知っておきたい用語集

用語意味
直系三田本店の山田拓美氏から直接のれん分けされた正統後継店。各地に展開しているが、スタイルや品質基準が厳しく管理されている
インスパイア系二郎の影響を受けた非直系の店舗。「二郎系」とも呼ばれる。味の方向性は似るが、直系とは別物
ロット1回に調理する麺の数（おおむね4〜8人分）。同じロットの客が同時に席に着き、コールもロット単位で取られる。待ち時間の目安にもなる
マシ・増しトッピングの量を増やすこと。「マシ」は「増し」と同義。「増し増し」はさらに多量
食券券売機で事前に購入するシステム。「食券先買い」の店では並ぶ前に購入する
天地返し丼をひっくり返すように混ぜること。麺をスープに浸けて食べやすくする一部常連の手法

食べ方のコツ

  • ヤサイの下に麺が埋まっているので最初にほぐすと食べやすい
  • 豚はスープに浸しながら食べると柔らかく感じる
  • 「天地返し」で麺をスープに沈める人も多い
  • 初回は「小ラーメン」から。思っているより量が多い

マナーについて

  • 食べきれる量を注文するのが望ましい（一般的なお店と同じ）
  • 満席時や行列中は会話を控えめに
  • 荷物はひざの上か足元に。通路を塞がないよう注意
  • ルールや雰囲気は店舗ごとに異なるため、初回は周囲をよく観察して
